# 🛠️ Algoritmos de Engenharia, Automação & Desenvolvimento

Este repositório reúne um conjunto de scripts e rotinas desenvolvidos para simulações de engenharia, sistemas de controle, automação industrial, eletrônica e soluções Web/Front-end.

---

## 📁 Estrutura do Repositório

```text
.
├── frontend/
│   ├── FiltroLinguagens.html       # Algoritmo de filtragem e busca no DOM
│   └── SimuladorAmortecimento.html # Simulador de controle (PI + Integrador)
├── java/
│   ├── ComunicacaoModbus.java       # Simulação de protocolo Modbus (Mestre/Escravo)
│   ├── InstrumentacaoRangeSpan.java # Cálculo de Range e Span em sensores
│   ├── PortaLogicaNAND.java        # Tabela verdade e simulação de lógica digital

│   ├── AmplificadorNaoInversor.py   # Simulação de ganho em AmpOp
│   ├── DimensionamentoEletrico.py   # Dimensionamento de cabos e disjuntores (NBR 5410)
│   └── MapeamentoIntervalosRCM.py   # Mapeamento de manutenção (RCM - Curva P-F)

    └── FolhaPagamentoBolsistas.hs   # Regras de negócio puras para gestão de bolsas
